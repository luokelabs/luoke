# 螺壳扫描 luoke-scan

- 仓库：`luoke-scan/`；进度：`luoke-scan/STATUS.md`；术语：`luoke-scan/CONTEXT.md`；本体怎么接：`luoke-scan/docs/host-interface.md`
- 本页由 luoke-scan 的会话维护。2026-11-03 由「螺壳体检 luoke-audit」改名；本页 2026-11-11 照 0.3.30 重写。

## 是什么

定期在空闲时只读地查一遍这台 Mac，找出垃圾和安全问题，说清是谁造成的、删了有什么风险，经 agent 和螺壳里的扫描页告诉用户；删不删由用户点。

- **原则**：是不是垃圾、能不能删、风险多高，由确定的规则决定；模型只做归纳和解释（经主控）。能用元信息（大小、时间、属主、签名、链接数）判断的就不读内容，需要内容时（重复文件的哈希、散落的密钥、AI 工具的 skill 和说明文件）在本机读，内容不进日志和记忆。扫描失败记成"没扫描"，不算没有发现。
- **查什么**（规则表见 `luoke-scan/STATUS.md`「已有的规则」）：
  - 空间：会重建的缓存、应用缓存和日志、卸载残留、装好了的安装包、重复文件、很久没动的项目（删前查 git：未推送提交、未提交改动、stash）和大文件、临时目录里成批没删的、空间去向和每天的增长、虚拟机磁盘和本机模型、Time Machine 本地快照、旧的 Intel 版 Homebrew。
  - 安全：会自己启动的程序（指向不存在的程序、没签名、用户可写、上一轮以后新出现的）、进程异常（孤儿、成批堆积、程序文件已删）、权限授予（应用已不在还拿着完全磁盘访问等）、系统的安全设置（FileVault、防火墙、SIP、Gatekeeper、自动更新、锁屏）、最近装的应用的签名和公证、明文存的凭据和散落的密钥（只记位置和类型）、对外监听的端口、ClamAV 和 YARA。
  - 供应链和 AI 工具：依赖里的已知恶意包（本机名单，比对锁文件和全局装的包）、依赖的安装脚本、包管理器让依赖在安装时跑脚本的设置、AI 工具的 skill 里的风险写法、本机模型的对话模板里有没有藏指令。
  - 运行状况：一直占满处理器的后台程序、内存吃紧、电池老化、发热。
- **形态**（2026-11-05 起）：Go 写的命令行程序，**打进螺壳.app，不生成自己的 .app**（顶层 ADR 0022 的 11-05 修订），跟螺壳一起升级、一起签名、公证。两个程序：
  - `luoke-scan`：扫描、出方案、执行方案、不用点就清。**从不开 socket、不监听网络**：给 agent 的 MCP 由螺壳本体每个请求起一次 `luoke-scan mcp --this-mac`，经标准输入输出，答完退出。打包的那一份启动时先认是不是螺壳起的，不是就退出。
  - `luoke-scan-admin`：只做要密码的那一步，以 root 跑。
  - 随包带 clamscan、freshclam、sigtool、yara 和它们要的库。
- **完全磁盘访问**授给螺壳本身（顶层 ADR 0021），由它起的扫描进程跟着用；没有时照样查能查的，并经 outbox 说明。
- **只做 macOS**，最低 26.2。
- **现状**（2026-11-11，版本 0.3.30）：
  - 已在内部版里：上面列的检查、增量扫描（FSEvents）、给 agent 的 MCP、螺壳里的三页（概览、状态、清理记录）、四类不用点就清（默认关，用户开启）、放回、要密码的删除（系统目录里的卸载残留、旧版 Homebrew）、三个生成任务、写记忆、清单搬成数据文件（`rules/`）。
  - 在谈、没做的：每一项「让 AI 看看」具体内容、占地方最多的文件夹能点开能清、运行状况的现查和一周趋势、病毒库改从镜像下载、扫描页和卡片的重设计。
  - 2026-11-11 起产品代码由 luoke-scan 会话做（顶层 ADR 0027）；安全相关的改动和 CI 配置归发版品控那条线。

## 对外提供

**给 agent：MCP 工具**（agent 工具协议版本 1），`transport` 是 `stdio`：螺壳本体每个请求起一次 `luoke-scan mcp`，把连接交给 agent。

| 工具 | 只读 | 做什么 |
|---|---|---|
| `scan_status` | 是 | 上一轮什么时候查的、查到多少、病毒库日期、哪些项没扫描及原因；正在查时带进度 |
| `scan_findings` | 是 | 按结论（放心删 / 要确认 / 仅供参考）、类别列发现，每条带依据和建议动作；给一张结果卡片 |
| `scan_now` | 是 | 现在查一轮（用户说"查一下"）；不改动用户的东西 |
| `scan_plan` | 是 | 对选中的发现出方案，给一张确认卡片；系统目录里要密码的几项是单独一份方案、单独一个按钮 |
| `scan_apply` | 否（列进 `actions`） | 执行用户在卡片上点了的方案；删除移到废纸篓。要密码的那份由螺壳本体弹授权框，`luoke-scan-admin` 以管理员身份做 |
| `scan_ignore` | 否（列进 `actions`） | 把一条发现标成"不用管" |
| `scan_restore` | 否（列进 `actions`） | 放回：清理记录里的一条，或一次清理的整批；原位置有同名的就放在旁边 |
| `scan_autoclean` | 否（列进 `actions`） | 开或关不用点就清的四类，参数 `{"on": true/false}`（旧的 `enable` 照旧认） |
| `scan_reveal` | 是 | 在访达里选中一条发现指的文件 |
| `scan_open_settings` | 是 | 打开系统设置里对应的页面 |
| `outbox_ack` | 是 | agent 告诉扫描某件事已经说过、答过或放下了 |

会改动东西的调用没有 `ai.luoke/user-action` 就拒绝，只执行扫描自己出过的方案。

**outbox**（`luoke://luoke-scan/outbox`，也认相对 id `outbox`）：

- `security`（urgent）：病毒库报毒、新出现的没人担保的会自己启动的程序、依赖里的已知恶意包；
- `space`（normal）：可用空间低于门槛；
- `needs-access`（low）：要用户在系统设置里给「螺壳」打开完全磁盘访问；
- 每一轮最多一件，编号 `round/<这一轮开始的时间>`：有自动清了的是 `auto-done`（normal，工具协议 §8a），否则有要用户决定的是 `findings`（low）；只剩仅供参考的不放。
- 同一件事每轮用同一个 `id`；用户放下以后不再当急事报。

**资源**（相对 id）：`summary`、`permissions`（`fda`、`auto`、`admin` 的状态）、`page/overview`（概览）、`page/mac`（状态）、`page/cleaned`（清理记录），都是 A2UI 基础页。

**配件清单**：`luoke-scan/packaging/luoke-accessory.json`，以它为准。要点：

- 配件标识 `luoke-scan`，bundle id `ai.luoke.scan`，`type` 是 `app`，没有常驻项，`memory: true`。
- 空闲任务两个，都每天一次、不在电池上跑：`update`（`update --this-mac`，不用模型，800 MB，20 分钟）、`scan`（`scan --this-mac --autoclean`，用模型，1500 MB，60 分钟，用到 `fda`）。螺壳本体只放行这两条写死的命令，改清单要同时改本体。
- 生成任务三个，都不是 main、走后台：`luoke-scan.explain`、`luoke-scan.identify`、`luoke-scan.skills`。
- 权限三项：`fda`（系统权限，归螺壳，没有时降级）、`auto`（不用点就清四类，由 `scan_autoclean` 开关）、`admin`（每次都要 Mac 的密码）。
- 数据目录 `~/.luoke-scan`。

**评测集**：`explain`（发现归纳成人话：准确、不夸大、给的动作能执行）、`identify`（只给路径、bundle id、大小、时间，说出可能是什么）、`skills`（skill 的语义检查）；另有不用模型的规则评测 `evals/cleanup/`（不用点就清的挑选，挑错必须是 0）。全部用合成的假用户目录。提示词在 `luoke-scan/prompts/`（顶层 ADR 0019）。

**规则清单**（`luoke-scan/rules/`，luoke#1 的社区贡献用）：认哪些位置、属于哪个工具、怎么清的名单是 JSON 数据文件（会重建的缓存、测试工具的临时文件夹前缀、虚拟磁盘和模型的位置、构建产物、要读的设置文件），每条带依据（`why`）和合成的测试样例（`samples`），测试照样例建假目录跑一遍；随版本发，运行时不下载。怎么加、哪些不收、样例不放真实路径和任何人的内容，写在 `luoke-scan/CONTRIBUTING.md`。结论和轻重、不用点就清、清之前的核对、密钥的样子、病毒特征留在代码里，不收外部贡献；清单里新加的条目只报、点了才清。贡献者署名的字段还没有（2026-11-11：等真有外部贡献、提出具体要求再加）。

## 对别的项目的需求

2026-11-11 交接时没有新提的需求。下面是已经商定、在用的约定；交接里还在核对有没有没写下来的（核完更新本节）。

- **对 luoke-core**：照 `docs/host-interface.md` 起扫描（每个请求一个进程、起之前核签名、描述符 3 上认本体、`LUOKE_HOST_FD` 提权通道、空闲任务经 `--run-tool`）；清单里空闲任务的命令和本体放行的两条一致。
- **对 luoke-agent**：照工具协议接上面的工具、卡片、outbox 和资源；要密码的方案和不要密码的分成两个按钮、两个方案编号。
- **对 luoke-mem**：写入口（`record --tool luoke-scan`）。
- **对 luoke-search**：没有。

## 在记忆里读写什么

- **写**：只写"发生了什么"，不写路径、目录清单、文件内容、哈希。五种记录：

  | topic | 什么时候写 |
  |---|---|
  | `scan-cleaned` | 用户处理了扫描给的清理方案 |
  | `scan-ignored` | 用户说「以后别提」 |
  | `scan-auto-cleaned` | 按规则自动清了（标明是规则做的，不拿来归纳习惯） |
  | `scan-malware` | 用户处理了报毒的文件 |
  | `scan-autoclean` | 用户开或关自动清理 |

- **读**：不读。

## 联网

只下载，不上传：病毒库由 freshclam 从 ClamAV 上游下载（每天最多一次）。规则和清单随版本发；恶意包名单从本机文件导入，不联网。

## 要守的底线

- **不带模型**（ADR 0018）：要模型只找主控的任务；主控不在时照样查，只是没有人话归纳。
- **数据不出本机**（ADR 0013）：数据目录 `~/.luoke-scan/`（只有本账户能读），排除出 Time Machine。
- **凭证不存值**：找到的密码、密钥、令牌只记位置和类型，不放进卡片和答复。
- **只读，改动只来自用户的点按**（工具协议 §5）；删除移到废纸篓。例外是四类不用点就清（顶层 ADR 0016 的 10-20、10-27 修订）：会重建的缓存直接删；装好了的应用的安装包、下载里别处还有一份的重复文件、测试工具留下的临时文件夹移进废纸篓，能放回；放回过的那类不再自动清；默认关，用户能整个关掉。
- **要管理员权限的**：用户不碰终端和命令；点了以后由螺壳本体弹授权框，一次一授权，不装常驻的 root 辅助程序。root 那一侧先把单独签名的 `luoke-scan-admin` 拷进只有 root 能写的文件夹、按发布签名核对这份拷贝、再用空环境跑；它不信方案文件，按和扫描同一个判定重新判定每一项，只动 root 拥有的、不跟随符号链接、核对 inode。别的账户的东西不碰。
- **不开 socket、不监听网络**；装好的扫描只由螺壳起。
- **不主动找用户**（ADR 0014）：不弹通知、不做菜单栏图标，只经 agent 的 outbox 和用户自己打开的扫描页。
- **跑得轻**：外部命令带超时和资源上限、低优先级、增量扫描，用户回来就让路。
