# 顶层 ADR

**有效的是 0001 起的这一组。** 每条只写现在有效的决定：规矩变了，直接改写那一条的正文，不在后面追加修订；整条被取代的挪进归档。0013–0028 已归档（放在团队的内部仓库），只当历史看，不再约束任何项目。2026-10-19 归档过的旧 0001–0012 和这一组同号，提到那一组时写「10-19 归档的 ADR 00xx」。

| 编号 | 说什么 | 取代 |
|---|---|---|
| [0001](0001-the-machine-is-the-boundary.md) | 本机就是边界：数据不出用户的设备，本机组件之间不设隐私限制；凭证不当内容存；记忆和搜索的本机数据默认加密存放 | 0013、0024 |
| [0002](0002-who-does-what.md) | 组件分工：模型在主控，理解在记忆，事情在工具，沟通、主窗口的界面和措辞在 agent；除输入法外都在螺壳.app 里、整体升级 | 0014、0022、0028 |
| [0003](0003-inference-and-scheduling-in-core.md) | 推理、权重和调度归主控，没有脱离主控的模型运行实例；任务协议；自己的引擎；高级用户的本机端点 | 0018、0020、0023 |
| [0004](0004-permissions-belong-to-luoke.md) | 系统权限授权给螺壳本身：组件经螺壳去要，开启时确认一次，只在用户操作后弹 | 0021 |
| [0005](0005-how-memory-thinks.md) | 记忆怎么想：工具记下发生了什么，记忆读原文、下结论；三档、先粗后细、看时间、反刍 | 0015 |
| [0006](0006-acting-for-the-user.md) | 替用户做事：能撤回的确认后自动做并提示，不可逆的永远要用户点；扫描自动清的四类 | 0016 |
| [0007](0007-prompts-in-files.md) | 提示词放成文件：每个配件一个 `prompts/`，顶层一页总览，证据记指纹 | 0019 |
| [0008](0008-release-open-source-and-brand.md) | 发布、开源和品牌：硬件门槛、渠道、默认开源、公开同步、许可；主控不再按版本认配件 | 0017 |
| [0009](0009-product-line-and-release-qc-split.md) | 产品线和发版品控分开：品控按版本做，不按 PR 做 | 0027 |
| [0010](0010-sprite-outside-luoke.md) | 螺壳小精灵：给没装螺壳的人的入口，可以自带一个小模型 | 0025 |
