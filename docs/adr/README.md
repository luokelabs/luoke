# 顶层 ADR

**2026-10-19 起，有效的是 0013 起的这一组。** 0001–0012 已经归档（放在团队的内部仓库 luoke-ops），只当历史看，不再约束任何项目。主人怀疑旧文档里"为了隐私自我设限"的字眼还在起作用，所以全部归档、重新写过。

| 编号 | 说什么 |
|---|---|
| [0013](0013-the-machine-is-the-boundary.md) | 本机就是边界：数据不出用户自己的设备，本机组件之间不设隐私限制；凭证不当内容存（10-21 修订：写进用户自己在用的账户不算外传；10-22 修订：深度搜索本机索引可存原值） |
| [0014](0014-who-does-what.md) | 分工：模型在主控，理解在记忆，事情在工具，沟通在 agent（10-21 修订：日历、浏览器桥由主控提供；10-24 修订：主控叫「螺壳」，agent 并进它；11-02 修订：主窗口由 luoke-agent 这边写；11-06 修订：跟 ADR 0022、0021 对齐） |
| [0015](0015-how-memory-thinks.md) | 记忆怎么想：工具记下发生了什么，记忆读原文、下结论；三档、先粗后细、看时间、反刍（10-22 修订：同一机构的事实合成一条，放宽两类可问的） |
| [0016](0016-acting-for-the-user.md) | 替用户做事：能撤回的确认后自动做并提示，不可逆的永远要用户点（10-20 修订：会重建的缓存确认一次后可自动清） |
| [0017](0017-v1-first-release.md) | v1 首发（10-20 修订：统一设计归 Jason，顶层仓库公开；10-22 修订：主控窗口和邮件助手网页 beta1 前改，开测 11-02；10-23 修订：记忆页、输入法设置也在 beta1 前改，主控和应用分开升级，改名「螺壳」，截止 10-28；10-29 修订：GitLab 镜像、公开仓库怎么同步；10-31 修订：公开仓库只在发公开版时同步，公开版只钉公开提交；11-01 修订：发给大家用的组件默认开源，agent 和体检一起上；11-02 修订：下一版是 beta 2，以 agent 上线为标准；11-03 修订：许可统一 Apache-2.0，应用可以自己发版；11-06 修订：分开升级和自己发版现在只对输入法） |
| [0018](0018-models-belong-to-core.md) | 推理和权重归主控，体系里没有脱离主控的模型运行实例（垂类模型也经主控跑；10-20 修订：digup 的嵌入由 luoke-search 接手；11-05 修订：一直加载的小模型（语音转写、嵌入）也由主控按任务统一管内存） |
| [0019](0019-prompts-in-files.md) | 提示词放成文件：每个配件一个 `prompts/`，顶层生成一页总览；证据记提示词指纹；11-04 修订：现在开始搬，Python 配件可放在包目录；改提示词要别人 Approve，安全相关的附三档逐题对比 |
| [0020](0020-own-thin-engine.md) | 引擎换成自己做的薄引擎，底层用 mlx-lm；先进内部版，beta 线和 11-02 的测试不换 |
| [0021](0021-full-disk-access-belongs-to-luoke.md) | 完全磁盘访问授权给螺壳本身：本体起主控时 disclaim，要读全盘的程序由本体核过声明和签名后起；11-06 修订：组件经螺壳请求权限，敏感权限装好后由螺壳当场要，并补记现状，「主控脱离」结论待定 |
| [0022](0022-apps-inside-luoke.md) | 除输入法外的应用都收进螺壳.app；11-05 修订：跟螺壳一起整体升级，不单独换；现在都打进包里，应用多了再改按需下载（仍由发布清单钉版本、跟螺壳一起换）；johnz 定进 beta 2 |
| [0023](0023-luoke-task-protocol.md) | luoke 自己的任务协议：声明优先级、权限、资源，主控统一调度（11-06 更正，原写引擎层），同优先级按时间；可做任务队列组件；方案待 johnz（luoke-ops#88） |

各项目文档里如果还引用"顶层 ADR 0001–0012"，以这里为准；和 0013–0017 冲突的，按新的改。
