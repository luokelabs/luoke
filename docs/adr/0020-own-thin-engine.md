# 0020 引擎换成自己做的薄引擎

状态：已定（主人 2026-10-30）

## 背景

主控现在用 oMLX 做推理引擎。oMLX 是给所有人用的本地模型应用，带了螺壳用不上、还要防着的能力（网页搜索和抓取、管理接口），包大，主控还依赖它没公开承诺的行为。螺壳跑的模型是配方里定死的几个，用不上这些。

luoke-audit 的对照实验比了 oMLX、mlx-serve 和一个只服务配方模型的薄引擎。带连续批处理和前缀缓存的薄引擎分拣更快、占内存更少，判断结果和 oMLX 一致；输入法打分、联想的结果也逐位一致。

## 决定

引擎换成螺壳自己做的薄引擎，底层用官方的 mlx-lm，不换 mlx-serve。

- 先进内部版跑，beta 线和 11-02 开始的测试不换。
- 怎么做、什么时候切由 luoke-core 定。ADR 0018 不变：推理和权重仍然归主控。
- 切换前要补上输入法自己的评测，并给「本机端点」留出路。

## 后果

- 引擎的代码归我们维护，升 mlx-lm 要自己跟。
- 主控不再依赖 oMLX 的私有接口和它带的整套依赖。
- 切换完成后，CONTEXT.md 里引擎的例子改掉。
