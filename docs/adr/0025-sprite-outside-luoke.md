# 0025 螺壳小精灵：螺壳之外的入口，可以自带小模型

状态：已定方向（2026-11-09，主人定）。先由主人这边做原型，验证两件风险；仓库 `luoke-sprite`（私有）。

## 背景

螺壳现有的几个场景都要先做点配置才能用上：邮件要应用密码，输入法要安装，探头要装扩展，搜索要完全磁盘访问。缺一个几乎零配置、打开马上出效果、方便分享的入口。目标是让人在三分钟内对「我的 Mac 跑本地 AI 有多强」产生兴趣，再把想深入的人领到螺壳。

小精灵是一个很轻的小程序：

- 打开后先检测这台 Mac；
- 用最快的办法把模型跑起来；
- 做一次以本地 AI 能力为主的自检，给出实测数字和对比，方便分享；
- 最后介绍螺壳能做什么。

界面是带动画的小角色，不是传统窗口。

选模型时比过三条路：

| 路子 | 结论 |
|---|---|
| Chrome 内置模型 | 不支持中文，只限 Chrome，读不到系统信息，放弃 |
| 苹果系统模型 | 在中国大陆买的设备目前用不了，Mac 什么时候开放也没有正式说法，只当检测到可用时的加速 |
| 小精灵自带小模型 | 中文好，所有 Apple 芯片 Mac 都能跑（含 8 GB），选它 |

ADR 0018 定的是「体系里没有脱离主控的模型运行实例，不设例外」。小精灵自带模型，所以要说清它和螺壳的边界。

## 决定

- **小精灵在螺壳之外**：给还没装螺壳的人的独立入口，不是螺壳的组件。它不进配方，不由螺壳安装，不读写记忆，不经 agent 说话。
- **没装螺壳时可以自带小模型**：按内存挑一个小档模型（例如 8 GB 用 0.8B、16 GB 以上用 2B，4-bit），关掉思考、只出短句。这是 ADR 0018 唯一的例外，只在没装螺壳时成立。
- **装了螺壳以后交给主控**：小精灵下过的模型交给主控接管，不重复下载；小精灵自己不再加载模型，改用主控的任务接口。
- **数据不出设备**（ADR 0013）：自检和模型都在本机。分享卡只放数字和模型写的那句话，不带用户的原始内容。
- **模型在国内要能稳定下载**：不依赖 Hugging Face，放在 luoke.ai 或魔搭这类国内下得动的地方。往我们自己的模型仓库上传新文件，照旧先问主人。
- **照实说**：
  - 现场测出来的数字照实写；
  - 推算和对照只用实验室各档的实测结果，和云端模型的类比要特别谨慎；
  - 引导到螺壳时按这台 Mac 的实际情况说：螺壳要 16 GB 和 macOS 26.2 以上，8 GB 的机器照实说螺壳暂时跑不了。

## 先验证的两件

1. 国内网络下，从打开到看到模型写的第一句话实际要多久（下载和第一次加载）。
2. 角色动画好不好玩：先做一个只有动画和假数据的界面原型，定手感。

## 还没定的

- 用哪个原生推理库（为了体积不打包 Python），它支不支持现在的小档模型；包的大小目标。
- 分发：签名公证的小 App，配 DMG、Homebrew、一行脚本三个入口，都指向同一个已公证的 App。
- 小精灵的展示以后搬进螺壳当首次体验的话，归谁做。
- 开不开源、英文名，以及和官网的关系。

## 修订（2026-11-09，更正）

- 背景表里「所有 Apple 芯片 Mac 都能跑（含 8 GB）」是目标，还没实测。
- 「先验证的两件」加第 3 件：8 GB 的机器上，小模型加小精灵本身的内存占用和速度。
