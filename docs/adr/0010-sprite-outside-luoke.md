# 0010 螺壳小精灵：给没装螺壳的人的入口，可以自带一个小模型

状态：有效。取代 0025。

## 决定

1. **小精灵是给还没装螺壳的人的轻量入口**：打开后检测这台 Mac，用最快的办法把模型跑起来，做一次以本地 AI 能力为主的自检、给出实测数字（方便分享），最后介绍螺壳能做什么。界面是带动画的小角色，不是传统窗口。目标是三分钟内让人对「我的 Mac 跑本地 AI 有多强」产生兴趣，再把想深入的人领到螺壳。
2. **在螺壳之外**：不是螺壳的组件，不进配方，不由螺壳安装，不读写记忆，不经 agent 说话。
3. **和螺壳一样 16 GB 内存、macOS 26.2 起**；内存不足或系统太旧的，开头照实说跑不了，不下载模型。
4. **没装螺壳时可以自带一个小模型**（暂定 Qwen3.5-2B 4-bit），关掉思考、只出短句。这是 0003「没有脱离主控的模型运行实例」唯一的例外，只在没装螺壳时成立。
5. **装了螺壳以后**，小精灵删掉自己下的模型，改用主控的任务接口。
6. **数据不出设备**：自检和模型都在本机；分享卡只放数字和模型写的那句话，不带用户的原始内容。
7. **模型在国内要下得动**：不依赖 Hugging Face，放在 luoke.ai 或魔搭这类国内下得动的地方；往我们自己的模型仓库上传新文件，照旧先问项目负责人。
8. **照实说**：现场测出来的数字照实写；推算和对照只用实验室各档的实测结果，和云端模型的类比要特别谨慎；自检里写「装上螺壳，这台 Mac 算哪一档」，照螺壳各档的实际体验写。
9. **可以给拖进来的文件起名字**：读出内容、给出建议的名字，用户点了才改，改了能撤销；拖进来的文件不用另要权限，不读用户没给它的文件。装了螺壳以后，这件活改走主控的任务。
10. 「从用的过程里自己长出新东西」要用基座模型和记忆，只在螺壳里做，不在小精灵里先做小实验。

## 为什么

螺壳现有的几个场景都要先做点配置才能用上（邮件要应用密码，输入法要安装，探头要装扩展，搜索要完全磁盘访问），缺一个几乎零配置、打开马上出效果、方便分享的入口。Chrome 内置模型不支持中文；苹果系统模型在中国大陆买的设备目前用不了，只当检测到可用时的加速；所以自带小模型。

## 还没定的

- 先验证的三件：国内网络下从打开到看到模型写的第一句话要多久；角色动画好不好玩；16 GB 的机器（M1）开着常用软件时，小模型加小精灵本身的内存占用和速度。
- 用哪个原生推理库（为了体积不打包 Python）；分发（签名公证的小 App，配 DMG、Homebrew、一行脚本三个入口）；开不开源、英文名、和官网的关系。
- 和螺壳界面的关系：第 2 条写「在螺壳之外、不经 agent 说话」，界面规范却把应用界面分成「桌面小精灵、首页、工作台」三层；小精灵当 agent 的桌面界面，原定 beta 2 之后再谈。暂按原文写「在螺壳之外」，等项目负责人定。
- 小精灵的展示以后搬进螺壳当首次体验的话，归谁做。
