应用

位置内容
/Applications/螺壳.app主控（也可能在 ~/Applications，以实际位置为准；改名前为 螺壳主控.app，升级时换成新名字）（内含自带 Python，记忆、邮件助手和 agent 核心的代码，螺壳搜索、螺壳扫描的程序，luoke 命令行；布局见配件清单与配方页）
~/Library/Input Methods/LuokeIME.app输入法
$TMPDIR/ai.luoke.inputmethod.Luoke.lock输入法单实例锁
~/.local/bin/luoke命令行链接（可选安装）

邮件助手、螺壳搜索、螺壳扫描收进螺壳.app 以前各是一个 .app，装在 ~/Applications；升到带上它们的螺壳后，旧的被挪进废纸篓，数据目录不动。

主控 ~/Library/Application Support/luoke-core/

开发版（bundle id ai.luoke.core.dev）用 luoke-core-dev/，结构相同。

路径内容
run/hub.sock任务接口 socket
logs/hub.log、logs/app.log、logs/jobs/日志（只记元数据）
logs/mail.log、logs/search.log、logs/luoke-scan.log、logs/agent.log本体起的邮件助手、螺壳搜索、螺壳扫描、agent 核心的标准错误（邮件助手起来后改写进自己数据目录的 service.log，这里只有它起来之前的输出）
engines/<版本>/、engine/<版本>/引擎包（发布版只留当前版本）；引擎运行目录（含引擎密钥 settings.json（0600）、engine.log、engine.pid.json）
models/模型；用户登记的模型在 user-<名字>
downloads/下载暂存（应用的包在 downloads/apps/）
state.json运行状态：常驻、螺壳里的应用开没开（enabled）、冒烟、探针、空闲任务、端点用量
settings.json能耗模式、电池、档、端点
endpoint-key、user-models.json端点密钥（0600）；登记的模型
local-verified.json本机放行
verified-history.json各配件版本由哪一版发布认可、当时放行哪些任务（每配件 3 个版本），供回到上一版本和主控升级后还没升级的应用使用
downloads/update/、run/update-mount.json检查更新下载的主控安装包，拷到暂存处后立即删除；run/update-mount.json 只为清理旧版留下的挂载而读
previous.noindex/换装前的旧版主控（连同它里面的应用；由换包脚本移入，不论原来在 /Applications 还是 ~/Applications）和单独成包的配件的旧版；单独成包的应用可在「应用」窗口里回到上一版本，卸载时一并删除
staging.noindex/升级主控时先放新版、核对签名，再由换包脚本移到装好的位置
run/upgrade.json、run/preselect.json升级标记（新主控读后删除）；安装器交来的预选应用
run/swap.sh、run/swap-result.json、logs/swap.log换包脚本、上次换包的结果（下次启动取走）、换包日志

记忆 ~/.luoke/

路径内容
mem.db（及 -wal、-shm）记忆，0600；可用 LUOKE_HOME 换位置
mem.db-ui.json、mem.db-learn.lock界面进程状态（0600）；归纳任务锁
mem.db.before-0.18第一次重新定档前的整份副本，14 天后或有内容被忘掉时删除
agent/agent 的 state.db、socket、日志
ime/输入法的设置、用户引擎、引擎数据、开发记录

邮件助手 ~/.luoke-mail/

不是装好的那份螺壳（例如开发版）里的邮件助手用 ~/Library/Application Support/luoke-mail/，结构相同。

路径内容
config.json设置
luoke.db邮件、建议、规则、清理、操作记录、精选
token、server.json、server.lock页面令牌；运行中实例的端口；单实例锁
idle.lock、service.pid、account-salt空闲工作锁；常驻实例的 pid；邮箱不透明键的随机值
run/agent.sockagent 接口（0600，默认打开，LUOKE_MAIL_AGENT=0 时不开）
service.log（及 service.log.1）日志（只记元数据，不含邮件内容）
run/notifications.json、run/old-logs-cleared最近 100 条通知的时间、发送方式和结果；旧版本留下的日志文字已清掉的标记

钥匙串

luoke-mail:imap（邮箱授权码）、luoke-mail:engine（直连模型服务的密钥）。邮件助手的数据目录不是 ~/.luoke-mail 时，服务名后面加这个目录的标识（如 luoke-mail:imap:<8 位十六进制>），一份数据目录一份授权码。

环境变量

变量作用
LUOKE_HUB_SOCKET指定主控 socket（指定后不回退默认位置）
LUOKE_HOME记忆所在目录
LUOKE_MAIL_HOME邮件助手数据目录（螺壳不是装好的那份时，本体和主控设为 ~/Library/Application Support/luoke-mail）
LUOKE_MAIL_PORT邮件助手网页端口（未用 --port 时）
LUOKE_MAIL_AGENT设为 0 时关掉邮件助手的 agent 接口（默认打开）
LUOKE_SEARCH_HOME螺壳搜索数据目录（发布版拒绝启动）
LUOKE_SEARCH_EMBED_TASK、LUOKE_SEARCH_OPENER、LUOKE_SEARCH_PHOTOS螺壳搜索开发用的开关（发布版删掉，LUOKE_SEARCH_DEV_APP 只在构建时用），见螺壳搜索页
PI_CODING_AGENT_DIRluoke launch pi 写入配置的位置
