记忆接口与表结构

Python 包 luoke_mem（仅标准库，3.9+）。工具只需 __init__、memory、sensitive 三个模块（不用带 prompts/：没有 prompts/labels.json 时，memory 用自带的同一份片段标题）；运行在主控里的配件应使用 GET /tasks 返回的 luoke_mem.path。

打开

  • Memory(path=None, tool="luoke")：工具使用。默认路径 $LUOKE_HOME/mem.db，未设置时为 ~/.luoke/mem.db。文件 0600，目录 0700；记忆文件或其 -wal、-shm、-journal 是符号链接时拒绝打开。文件不存在时创建（0600）；命令行 sources、forget-tool、learn、mcp 在文件不存在时不创建（record 会创建）。
  • WholeMemory(path=None, *, regrade=True)：整份记忆，供记忆自己的界面、命令行、归纳任务和工具协议使用；打开时执行重新定档（只降不升）、以前的事、相近话题合并，regrade=False 时不做（工具协议的每个请求这样打开）。第一次定档前把整份记忆复制为 mem.db.before-0.18，14 天后或有内容被忘掉时删除。
  • 文件 schema 比库新得多（千位不同）时抛 TooNew。

工具接口

记录

方法说明
record(speaker, kind, text, *, topic, data, ref, happened_at, sensitive)写一条记录；happened_at 须是 YYYY、YYYY-MM、YYYY-MM-DD 或带时间，位数要全（不填为当前时间；以前收下的读不了的时间按没有日期处理），topic、ref 须是文字，否则抛 ValueError；正文和 data 中的字符串先遮去凭证；本工具被用户停学时返回 0、什么都不写
redate(rid, happened_at)修正本工具一条记录的发生时间（时间格式同 record）
records(*, tool="", topic, kind, speaker, ref, since, limit)tool="" 为本工具，传工具名读该工具，None 读全部
forget_records(*, topics, since, until, match, keep_cited)删除本工具的部分记录，只依赖这些记录的理解一并删除
forget_tool(tool=None, *, dry_run)删除本工具写入的全部内容；用户说过的话和表过态的理解转到记忆名下保留

理解

方法说明
state(kind, text, …)用户亲口说的，直接为"确定"
propose(kind, text, cites, …)推测，为猜测（本工具被停学时返回 None，conclude 同）；事实的依据里有来信够多（同一来源 ≥ 6 封、跨 ≥ 3 个月、打开 ≥ 2 封、6 个月内仍有，EVIDENCE）且不涉健康、法律、宗教政治时直接生效
conclude(kind, text, cites, …)由用户自己的记录得出；依据须全部来自用户，按定档规则为比较确定或猜测
confirm(nid) / reject(nid) / was(nid) / later(nid) / revise(nid, text)用户的决定：确认、否定、以前是、以后再说、改写
reject_family(nid)「这一类都不要」：把这条所在一类里用户还没表态的（待确认和观察中）都标为否定，返回条数
notes(kinds, status, tool, confidence)默认只返回生效的（比较确定和确定）；每条带 confidence、data、auto、fresh
note(nid)一条理解及其全部依据（含原文）
recent(since, limit)未经用户表态而直接生效的推断
context(kinds, limit=600, labels=None)按类别拼成供模型使用的一段文字；每段标题取 LABELS（luoke_mem/prompts/labels.json，没有这个文件时用 memory 里同样的一份），labels 可逐个换掉
forget(nid)删除理解、其历史版本及只被它引用的记录

想问的和建议

方法说明
asks(status=["open"], *, tool)未过期的问题和建议；tool 筛出与某工具相关的
reply(aid, choice, text=None)交回用户的回答：关于某条理解的问题 yes / no / past / revise / later（later 把问题记为 later，7 天后由反刍重新提出）；自由问题 answer / later（7 天后再问）；建议 useful（关于习惯的建议同时确认该习惯）/ useless / never；任何一种都可以 archive（同 archive()）；其他组合抛 ValueError
archive(aid)归档：状态改为 archived，不算回答、不过期；这件不开着或已经过期时抛 ValueError
unarchive(aid)放回：重新开着，归档时还剩几天就还剩几天；返回新编号，旧编号不再有效；不是归档着的抛 ValueError

停学

方法说明
stopped()用户关了、记忆不再从它学的应用，每个 tool 和关的时间；哪个应用都能读
WholeMemory.stop_learning(tool) / resume_learning(tool)关、再打开；只给记忆自己的界面和工具协议用。忘掉一个应用写的、清空整份记忆都不动这份名单

人（WholeMemory）

方法说明
entities(kind=None, status=None)人的列表，默认 active 和 proposed，关于他的理解多的在前
entity(eid)一个人：名字、别的叫法和地址、关系、写信的档案 contact、关于他的理解 about
hotwords(limit=50)给语音的热词：人名最多 max(1, int(limit × 0.4)) 个、英文专名最多 max(1, int(limit × 0.2)) 个，其余给用户自己的说法，没用完的名额按把握回填；不取敏感的、超过 24 字的、带换行的；确定的在前
link_people()从头重认一遍人，返回 active 加 proposed 的人数；反刍时、合并和拆开后调用，打开记忆时不调用
rename_person(eid, name)改名：这个人定为 active，同时记一条用户说的常用说法
merge_people(keep, other)并成一个：other 标为 merged，它的理解挪到 keep
split_person(eid, alias)把一个叫法或地址拆成另一个人，返回新编号；没有这个叫法、或只剩这一个叫法时抛 ValueError
reject_person(eid)不是一个人：标为 rejected，它名字的常用说法作废
forget_person(eid)删关于这个人的理解、他地址的 mail-contact 记录、这个人和并进来的；返回 {notes, records}

工具协议（luoke_mem.agent）

luoke-agent 工具协议版本 1 的工具一侧，mcp 命令每次答一个请求。消息最多 1 MB（超过答 -32600）；MCP 协议版本 2026-07-28，params._meta 里带了别的版本答 -32602 并附 supportedVersions。方法：server/discover（服务名 luoke-mem，版本同包）、resources/list、resources/read、tools/list、tools/call；没有 id 的通知不答。读不懂答 -32700，未知方法 -32601，没有的资源、给不收参数的资源带了参数 -32002；工具自己出错答 -32603「工具内部出错」，标准错误只记方法、登记过的工具名或资源、异常类型和出错位置。整份记忆以 regrade=False 打开。

清单 capabilities

由 agent.capabilities() 给出，同一份写在 packaging/accessory.json 里：protocol 1、transport "stdio"；reports：question「记忆想问的事」、suggestion「记忆的建议」，默认都是 normal；actions：mem_reply、mem_note、mem_forget_tool、mem_learn、mem_forget_all、mem_person、mem_archive（都 writes: true）；data（和 actions 同一层）：recent、helped、asks、ask、notes、people、person、note、sources、data；service：summary: true、pages（overview 概览、all 全部记忆、people 人物三个是标签；settings 设置带 hidden 和 icon: "settings"；item 一条理解、asks 归档的问题，和 0.37 以前的 guesses、kept、sources 都带 hidden）、ui.open: "mem_open"（只给不认 pageArgs 的核心）。

原始数据 data/*

主窗口的记忆页由 luoke-agent 的核心拼，读这几样。每个答复都有 v（形状的版本，现在是 1，只加字段不升）和 ready；ready: false 时只有 problem：empty（还没有记忆）、too_new、links、locked、broken。时间是本机时间 YYYY-MM-DD HH:MM:SS。参数用默认值时不写。

一条理解（下面的 items、note、about）：id、text、kind、status、pending（待确认）、confidence（guess、likely、sure）、origin、topic、entity、formed_at、decided_at、fresh（最新依据的时间）、cites（依据几条）、sources（依据来自哪些应用，luoke-mem 是用户自己说的）、alike（同一话题挨着的还有几条，只在 data/notes 里）。

资源参数内容
data/recent—最近 30 天没问就记下的，新的在前，最多 20 条，不含常用说法：since、items
data/helped—记忆不记谁读了什么：recorded: false、items: []
data/asks—概览上要确认的，最多 3 件。每件 id、kind（question / suggestion）、type、rank、created_at、expires_at、answer。type：same_person（basis 为 name_inside 或 same_local，people 两个，各 by、entity、name、relations、addresses）；note（basis 为 quiet 机构的信停了、reworded 来信说法变了并带 newer、guess 别的猜测；note 是那条理解）；own（记忆自己的问题，text）；unsubscribe、habit、suggestion（about_note、action、evidence、text）
data/askid一件，哪个单子上的都行（outbox 里的 ask/<id> 也是）。字段同 data/asks，再加 status、text、why；facts（「为什么」凭的事实：same_local 的 local；quiet 的 letters、last；reworded 的 newer；habit 的 account、sender、name、category、action；unsubscribe 的 sender、times、count、days；别的是 {}）；affects（答了改动哪个应用的哪件事，[{tool, use}]）；cites（依据的记录，新的在前，最多 50 条，cites_total 是一共几条）；replies（能怎么答，每个是 mem_reply 除 ask 以外的参数，archive 每件都有）；write（要带用户写的字的 choice）。不在了答 found: false
data/notesfilter（all 默认、pending、past、rejected 或一个 kind）、q、p、n（默认 20，最多 100）全部记忆。all 是生效的和攒够依据的猜测，不含常用说法和精选的口味。答 filter、q、page、pages、total、waiting（还在攒依据、不列的猜测几条）、counts（每个筛选各几条，不受 q 影响）、items
data/peopleq、p、n有理解或写信记录的人，写得多的在前。每人 id、name、status、notes、relations、top（关系以外最有依据的一条）、contact（first、last、months、count、lapsed、together）
data/personid一个人，同上，再加 aliases、profile（完整的写信档案）、about（关于他的全部理解）。不在了答 found: false
data/noteid、p、n（默认 50）一条理解（加 why、superseded_by、valid_from、valid_to）和全部依据 cites（id、tool、speaker、kind、topic、text、happened_at、recorded_at、sensitive）；merged 是并进来的说法
data/sources—每个写过记忆、或关了停学的应用：tool、on（学不学）、stopped_at、records、notes、topics（写过哪几类记录、各几条）、last
data/data—tidied（上次整理 at 和 counts）、next: "idle"、typing（上次归纳打的字 at、outcome）、kept（记住的事几条）、terms（输入法词条几条）、archived_asks

affects 按理解的种类：fact 是 *（每个工具都当作关于用户的事实）；interest 邮件助手 digest_prefer；dislike digest_avoid；preference habit；term 输入法 candidates_first；taste digest_taste；建议照它的 action；same_person 是 luoke-mem 的 merge_people。「是不是同一个人」交 mem_reply 的 choice: "answer"、text 为「是」或「不是」。

卡片上的按钮

都调 mem_reply，上下文 {ask, choice}，要文字的再带 text：

哪种按钮 → choice
关于某条理解的问题（有 about_note）输入框「不太对的话，改成」；对 → yes、不对 → no、以前是，现在不是 → past、按我改的 → revise（text 取输入框）、以后再说 → later
带选项的问题单选「选一个」；交回 → answer（text 取选中的）、以后再说 → later
是非问题是、不是 → answer（text 为「是」「不是」）、以后再说 → later
其他问题输入框「你的回答」；交回 → answer、以后再说 → later
处理习惯（action.capability 为 habit）或是非类的建议好 → useful、不用 → useless、别再提 → never
其余建议知道了 → useful、别再提 → never

每张卡片最后有「归档」→ archive。有 about_note 的卡片多一个「在螺壳记忆里看」：核心认 pageArgs 时是 agent.open_page（{page: "item", args: {id}}），否则 → mem_open（{note}）。

工具

七个写入工具没带 ai.luoke/user-action（surfaceId、componentId、at 都是非空字符串）答 needs_user_action；缺必填参数答 invalid；记忆文件不存在、比这份 luoke_mem 新、旁边有符号链接、正被锁着或读不了时答 not_ready，带一句说明。失败都是 isError: true，原因码在 structuredContent.code。

工具参数说明
mem_reply（写）ask、choice，可带 text照 reply() 交回。choice 要合这件的种类（建议 useful / useless / never；关于理解的问题 yes / no / past / revise / later；其他问题 answer / later；都可以 archive），revise、answer 要有 text，text 里有凭证不收，都答 invalid（卡片留着）。这件已不开着，或它问的那条理解已经定了、被取代或忘掉时，答「这条已经变了……」。成功答一句话，structuredContent 带 card（换掉原卡片，不带 createSurface）和 done: true；「这条已经变了」也一样
mem_note（写）note、op（confirm / reject / forget / revise / split / reject_family）、sure、text、family理解的状态不合这个动作时答 stale（说过不对的只能 forget）；forget 要 sure: true；revise 的 text 最多 200 字、不收凭证，写的是「不对」「那是以前的事了」这类短话时按否定、以前的事处理，答的话照实写；split 只对并进来的（superseded）说法，拆出来成一条单独的猜测；reject_family 的 family 是页上数的那几条编号（2 到 5000 个），和现在这一类对不上答 stale、一条都不否定。只答一句话
mem_forget_tool（写）tool、sure即 WholeMemory.forget_tool；tool 须写过东西、不是 luoke-mem，否则 stale；要 sure: true。答删掉的记录和理解条数
mem_learn（写）tool、on设置里每个应用的开关：on 是点了以后学不学；即 stop_learning / resume_learning。不用确认
mem_forget_all（写）confirmconfirm 是「清空」才清空整份记忆，否则 invalid
mem_person（写）person、op（reject / forget / rename / merge / split）、sure、name、other、aliasforget、split 要 sure: true，没勾答 invalid；rename 带 name，merge 带 other（页上选的那个人），split 带 alias（叫法或邮箱地址）。只答一句话
mem_archive（写）op（archive / back）、asks（1 到 500 个编号）归档或放回页上列出的几件；一件都没做成答 stale
mem_open（只读，_meta 带 ai.luoke/where: mac）note，或 page: "recent" / "people"只给不认 pageArgs 的核心。起或找到整份记忆的页面，在浏览器里打开到这一条、「最近记下的」或「人」；没有记忆答 not_ready，打不开答 failed
outbox_ack（只读）id、state只答「好。」，不记：答了的由 mem_reply 关掉，用户放下的在记忆里照旧开着

记忆自己拼的页 page/*

luoke-agent 照 data/* 拼完之前，这些页照旧答。核心在请求的 clientCapabilities.experimental["ai.luoke/a2ui"].features 里列了 pageArgs 时，读页可以带参数：最多 4 个，键是小写字母开头、最多 16 个字符的短名字，值最多 200 字，同一个键写几次取第一个；参数不对（不认识的类、没有的编号、超出的页）照没带或最近的那一页画，不报错。其他认的 features：bigPages（一页放得更多）、confirm（删之前由窗口弹确认，按钮带 sure: true 和 confirm: {title, text, label}）、rowOpen、fieldSubmit、openPage。一段文字最多 2000 字。

页参数内容
overview 概览—最近了解到的（最多 5 条，不含常用说法），每条「不对」；想跟你确认的最多 3 件，按钮同卡片。没有总条数
all 全部记忆（kept 同）kind 或 view（pending / past / rejected）、q、p生效的和待确认的一个列表；只凭一条记录的猜测不列。每条 对（猜测）、不对、看依据、忘掉 → mem_note；以前的事是「现在还是」「不对」；说过不对的只有「忘掉」。一页 8 条，大页 18 条。guesses 是它的待确认
item 一条理解id、p原话、类别和状态、理由；对 / 不对、现在还是、改写、「这一类都不要（N 条）」、忘掉、并进来的说法各一个「拆出来」→ mem_note；全部依据原文按 p 翻页。没带 id 时只有一句说明
people 人物p；一个人：id、who、wp列表只列有话可说的人，每人一句话，行上写 open。一个人的页：改名、叫法和地址各一个「不是这个人」、选另一个人「并成一个」（wp 翻组、who 按名字或邮箱找）、关于这个人的理解、不是一个人、忘掉 → mem_person
settings 设置（sources 同）tool、day、p、forget=1每个应用一行：学不学的开关（variant: "switch"）→ mem_learn，看每天记了什么，忘掉它写的（forget=1 先试跑、说会删多少）→ mem_forget_tool；上次整理；「数据」里记住的事和输入法词条的条数；清空整份记忆 → mem_forget_all
asks 归档的问题p已归档的每件一个「放回」→ mem_archive

核心没列 pageArgs 时带了参数也不管：每页最多列 15 条，多的写「还有 N 条，在整份记忆里看」，页上有「打开整份记忆」；删除用勾选框「我知道删了找不回来」，清空要在输入框里写「清空」。没有记忆时每页只有标题和一句说明。

界面

独立进程，监听 127.0.0.1 随机端口；页面令牌在 ?t=，接口令牌在 X-Luoke-Token；校验 Host 和 Origin；600 秒无请求退出。路由：/api/ping、/api/summary、/api/overview、/api/records、/api/notes、/api/note、/api/recent、/api/people（/api/summary 里带人数 people）；修改用 POST /api/change（confirm、reject、reject-family、forget、revise、split（把并进来的一条拆出来）；修改文字截到 200 字，拒绝凭证）、/api/person（rename、merge、split、reject、forget）、/api/forget-tool（拒绝 luoke-mem）、/api/forget-all（需输入「清空」）。/api/grants、/api/grant 为遗留接口，不再影响读取。页面有「人」一页（地址带 view=people 时直接开到这里）：每人的名字、关系、别的叫法、写信的档案和常谈的话题，能改名、并成一个、拆出某个叫法、说不是一个人、忘掉。网页上没有归档。界面状态（pid、端口、令牌）存于 mem.db-ui.json（0600）。
