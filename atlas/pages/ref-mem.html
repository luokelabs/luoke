记忆接口与表结构

Python 包 luoke_mem（仅标准库，3.9+）。工具只需 __init__、memory、sensitive 三个模块（不用带 prompts/：没有 prompts/labels.json 时，memory 用自带的同一份片段标题）；运行在主控里的配件应使用 GET /tasks 返回的 luoke_mem.path。

打开

  • Memory(path=None, tool="luoke")：工具使用。默认路径 $LUOKE_HOME/mem.db，未设置时为 ~/.luoke/mem.db。文件 0600，目录 0700；记忆文件或其 -wal、-shm、-journal 是符号链接时拒绝打开。文件不存在时创建（0600）；命令行 sources、forget-tool、learn、mcp 在文件不存在时不创建（record 会创建）。
  • WholeMemory(path=None, *, regrade=True)：整份记忆，供记忆自己的界面、命令行、归纳任务和工具协议使用；打开时执行重新定档（只降不升）、以前的事、相近话题合并，regrade=False 时不做（工具协议的每个请求这样打开）。第一次定档前把整份记忆复制为 mem.db.before-0.18，14 天后或有内容被忘掉时删除。
  • 文件 schema 比库新得多（千位不同）时抛 TooNew。

工具接口

记录

方法说明
record(speaker, kind, text, *, topic, data, ref, happened_at, sensitive)写一条记录；happened_at 须是 YYYY、YYYY-MM、YYYY-MM-DD 或带时间，位数要全（不填为当前时间；以前收下的读不了的时间按没有日期处理），topic、ref 须是文字，否则抛 ValueError；正文和 data 中的字符串先遮去凭证
redate(rid, happened_at)修正本工具一条记录的发生时间（时间格式同 record）
records(*, tool="", topic, kind, speaker, ref, since, limit)tool="" 为本工具，传工具名读该工具，None 读全部
forget_records(*, topics, since, until, match, keep_cited)删除本工具的部分记录，只依赖这些记录的理解一并删除
forget_tool(tool=None, *, dry_run)删除本工具写入的全部内容；用户说过的话和表过态的理解转到记忆名下保留

理解

方法说明
state(kind, text, …)用户亲口说的，直接为"确定"
propose(kind, text, cites, …)推测，为猜测；事实的依据里有来信够多（同一来源 ≥ 6 封、跨 ≥ 3 个月、打开 ≥ 2 封、6 个月内仍有，EVIDENCE）且不涉健康、法律、宗教政治时直接生效
conclude(kind, text, cites, …)由用户自己的记录得出；依据须全部来自用户，按定档规则为比较确定或猜测
confirm(nid) / reject(nid) / was(nid) / later(nid) / revise(nid, text)用户的决定：确认、否定、以前是、以后再说、改写
reject_family(nid)「这一类都不要」：把这条所在一类里用户还没表态的（待确认和观察中）都标为否定，返回条数
notes(kinds, status, tool, confidence)默认只返回生效的（比较确定和确定）；每条带 confidence、data、auto、fresh
note(nid)一条理解及其全部依据（含原文）
recent(since, limit)未经用户表态而直接生效的推断
context(kinds, limit=600, labels=None)按类别拼成供模型使用的一段文字；每段标题取 LABELS（luoke_mem/prompts/labels.json，没有这个文件时用 memory 里同样的一份），labels 可逐个换掉
forget(nid)删除理解、其历史版本及只被它引用的记录

想问的和建议

方法说明
asks(status=["open"], *, tool)未过期的问题和建议；tool 筛出与某工具相关的
reply(aid, choice, text=None)交回用户的回答：关于某条理解的问题 yes / no / past / revise / later（later 把问题记为 later，7 天后由反刍重新提出）；自由问题 answer / later（7 天后再问）；建议 useful（关于习惯的建议同时确认该习惯）/ useless / never；其他组合抛 ValueError

工具函数

mask_secrets(text)（遮去密码、验证码、密钥、通过 Luhn 校验的卡号、证件号）、find_secrets、sensitive_kinds(text)（健康、法律、宗教政治）、confidence(note)、default_path()。

命令行

命令说明
python -m luoke_mem [--path P] sources各工具写入的条数
forget-tool <tool> [--dry-run]忘掉某工具写入的内容；luoke-mem 被拒绝（说明原因，退出码 1）
ui [--open] [--note N] [--view recent]打印界面地址
app [--note N] [--view recent]在浏览器中打开界面（luoke://memory 的入口）
learn [--force] [--again] [--hub SOCK]运行一次归纳；--force 有新记录就跑；--again 从头重新归纳（打字记下的不重复；话题线从头读，用户没表态的话题只在有 topics 任务的 Mac 上换成新归纳的，没有这个任务的 Mac 保留原有的）；已有一个在跑时直接返回
record --tool <工具>替没有 Python 的工具写记录（螺壳扫描用）：标准输入一行一条 JSON，字段同 record()，没给 sensitive 时按文字标；标准输出一行对一行回 {"id"} 或 {"error"}，一行出错不影响其他行；有失败的行退出 1，工具名不对或记忆打不开退出 2；不能以 luoke-mem 的名义写
mcp [--clock T]工具协议的一个请求（清单 commands.mcp，见下「工具协议」）：标准输入读到结尾、取第一条非空行，标准输出答一行，退出码 0；--clock 写成 YYYY-MM-DDTHH:MM:SS，把时钟定在这个本机时间（录场景样例用）

工具协议（luoke_mem.agent）

luoke-agent 工具协议版本 1 的工具一侧，mcp 命令每次答一个请求。消息最多 1 MB（超过答 -32600）；MCP 协议版本 2026-07-28，params._meta 里带了别的版本答 -32602 并附 supportedVersions。方法：server/discover（服务名 luoke-mem，版本同包）、resources/list、resources/read、tools/list、tools/call；没有 id 的通知不答。读不懂答 -32700，未知方法 -32601，没有的资源 -32002；工具自己出错答 -32603「工具内部出错」，标准错误只记方法、登记过的工具名或资源、异常类型和出错位置。整份记忆以 regrade=False 打开。

清单 capabilities

由 agent.capabilities() 给出，还没写进 packaging/accessory.json（只在场景样例的 manifest.json 里）：protocol 1、transport "stdio"；reports：question「记忆想问的事」、suggestion「记忆的建议」，默认都是 normal；actions：mem_reply、mem_note、mem_forget_tool、mem_forget_all（都 writes: true）；service：summary: true、pages（overview 概览、guesses 猜测、kept 记下的、sources 各应用写的）、ui.open: "mem_open"。

卡片上的按钮

都调 mem_reply，上下文 {ask, choice}，要文字的再带 text：

哪种按钮 → choice
关于某条理解的问题（有 about_note）输入框「不太对的话，改成」；对 → yes、不对 → no、以前是，现在不是 → past、按我改的 → revise（text 取输入框）、以后再说 → later
带选项的问题单选「选一个」；交回 → answer（text 取选中的）、以后再说 → later
是非问题是、不是 → answer（text 为「是」「不是」）、以后再说 → later
其他问题输入框「你的回答」；交回 → answer、以后再说 → later
处理习惯（action.capability 为 habit）或是非类的建议好 → useful、不用 → useless、别再提 → never
其余建议知道了 → useful、别再提 → never

有 about_note 的卡片多一个「在螺壳记忆里看」→ mem_open（{note}）。

工具

四个写入工具没带 ai.luoke/user-action（surfaceId、componentId、at 都是非空字符串）答 needs_user_action；缺必填参数答 invalid；记忆文件不存在或比这份 luoke_mem 新时答 not_ready。失败都是 isError: true，原因码在 structuredContent.code。

工具参数说明
mem_reply（写）ask、choice，可带 text照 reply() 交回。choice 要合这件的种类（建议 useful / useless / never；关于理解的问题 yes / no / past / revise / later；其他问题 answer / later），revise、answer 要有 text，text 里有凭证不收，都答 invalid（卡片留着）。这件已不开着时答「这条已经变了……」。成功答一句话，structuredContent 带 card（换掉原卡片，不带 createSurface）和 done: true；「这条已经变了」也一样
mem_note（写）note、op（confirm / reject / forget）、sure理解须是 proposed、observed、active 或 past，否则 stale；forget 要 sure: true。只答一句话
mem_forget_tool（写）tool、sure即 WholeMemory.forget_tool；tool 须写过东西、不是 luoke-mem，否则 stale；要 sure: true。答删掉的记录和理解条数
mem_forget_all（写）confirmconfirm 是「清空」才清空整份记忆，否则 invalid
mem_open（只读，_meta 带 ai.luoke/where: mac）note，或 page: "recent"起或找到整份记忆的页面，在浏览器里打开到这一条或「最近记下的」；没有记忆答 not_ready，打不开答 failed
outbox_ack（只读）id、state只答「好。」，不记：答了的由 mem_reply 关掉，用户放下的在记忆里照旧开着

四页

页内容
overview 概览概览那句话；各类生效理解的条数（不含精选口味）；最近 30 天没问就记下的，最多 5 条（文字、类别、来源、日期）；最近 14 天各应用写入的记录条数；还在攒证据的别人来信事实有几条；「打开整份记忆」
guesses 猜测状态 proposed、observed 的理解，不含引用了别人来信的事实；每条带类别、依据条数、日期，对 → mem_note confirm、不对 → reject；「在整份记忆里看依据」
kept 记下的生效的理解（不含精选口味）和勾选框「我知道删了找不回来」；不对 → reject、忘掉 → forget（sure 取勾选框）；「打开整份记忆」
sources 各应用写的勾选框；每个应用（不含 luoke-mem）的记录、理解条数和「忘掉…写的」→ mem_forget_tool；记忆自己名下的理解条数；输入框和「清空整份记忆」→ mem_forget_all（confirm 取输入框）

每页最多列 15 条理解，多的写「还有 N 条，在整份记忆里看」。没有记忆时每页只有标题和一句说明。

界面

独立进程，监听 127.0.0.1 随机端口；页面令牌在 ?t=，接口令牌在 X-Luoke-Token；校验 Host 和 Origin；600 秒无请求退出。路由：/api/ping、/api/summary、/api/overview、/api/records、/api/notes、/api/note、/api/recent；修改用 POST /api/change（confirm、reject、reject-family、forget、revise、split（把并进来的一条拆出来）；修改文字截到 200 字，拒绝凭证）、/api/forget-tool（拒绝 luoke-mem）、/api/forget-all（需输入「清空」）。/api/grants、/api/grant 为遗留接口，不再影响读取。界面状态（pid、端口、令牌）存于 mem.db-ui.json（0600）。
